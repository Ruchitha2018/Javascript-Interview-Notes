# Who created Javascript ?

JavaScript was created by **Brendan Eich** in **1995** while he was working at **Netscape Communications**.

### Key interview facts

| Fact                | Answer       |
| ------------------- | ------------ |
| **Creator**         | Brendan Eich |
| **Year created**    | 1995         |
| **Company**         | Netscape     |
| **Original name**   | Mocha        |
| **Later name**      | LiveScript   |
| **Final name**      | JavaScript   |
| **Standardization** | ECMAScript   |

### Interview answer

> **JavaScript was created by Brendan Eich in 1995 at Netscape. It was initially called Mocha, later renamed LiveScript, and eventually JavaScript. The language was standardized as ECMAScript by ECMA International.**
